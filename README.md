# hwp-page — 한글 쪽 설정 MCP (Claude Code 스킬)

한글(hwp/hwpx) 문서를 Claude Code 로 다룰 때 쓰는 MCP 서버와 스킬입니다.

- **쪽 방향 바꾸기** — 한글 COM 으로는 저장할 때 가로 설정이 안 먹는 문제를 hwpx 파일을 직접 고쳐 해결
- **여백·용지·본문 글자 크기** 바꾸기 (제목 등 다른 크기도 같은 비율로)
- **부호 문단 내어쓰기** — «1) 가. - ①» 로 시작하는 문단의 둘째 줄을 부호 뒤 글자에 맞춤

## 설치 (3분)

1. 이 페이지 위쪽 초록색 **[Code] → [Download ZIP]** 을 눌러 받고, 압축을 풉니다.
2. 풀린 폴더 안의 **`hwp-page` 폴더**를 아래 위치에 통째로 복사합니다.
   (파일 탐색기 주소창에 그대로 붙여넣고 Enter)
   ```
   %USERPROFILE%\.claude\skills
   ```
   `skills` 폴더가 없으면 새로 만듭니다. 복사 후 `...\.claude\skills\hwp-page\SKILL.md` 가 있어야 합니다.
3. VS Code 를 껐다 켜고, 클로드에게 이렇게 말합니다.
   ```
   hwp-page 설치해줘
   ```
   클로드가 파이썬 라이브러리 설치와 MCP 등록을 해 줍니다.
4. 안내대로 **VS Code 를 한 번 더 껐다 켜면** 끝입니다.

## 쓰는 법

클로드에게 그냥 말하면 됩니다.

- «이 한글 파일 가로로 바꿔줘»
- «여백 좌우 20mm 로 줄여줘»
- «글자 한 단계 키워줘»
- «부호 문단 내어쓰기 맞춰줘»

고치기 전 원본은 `파일이름.hwpx.bak` 으로 남습니다. 결과가 마음에 안 들면 `.bak` 을 지우고 원래 이름으로 바꾸면 됩니다.

## 필요한 것

- Windows
- Python 3.10 이상 ([python.org](https://www.python.org/downloads/windows/))
- 한글(한컴오피스) — 내어쓰기 기능에만 필요. 쪽 방향·여백·글자 크기는 한글 없이도 됩니다.
- Claude Code

## 한계

- 쪽 방향·여백·글자 크기는 `.hwpx` 만 됩니다. `.hwp` 는 한글에서 «다른 이름으로 저장 → HWPX» 후 사용하세요.
- 방향만 바꾸므로, 세로에 맞춰 만든 표는 가로로 돌리면 오른쪽이 비어 보입니다.
